The Gutztools post-processing package with Python. Gutztools has two main package: PyUtil and SymmAtom.

PyUtil is used to produce the input data output.* for Gutzaria and the input data for SymmAtom. It is also used to build the renormolization bands after running Gutzaria. PyUtil is more like a powerful scipyt to deal with the data producing by Gutzaria and to produce the data for Gutzaria.

SymmAtom is used to solve the atomic problem to produce the input data for Gutzaria.
